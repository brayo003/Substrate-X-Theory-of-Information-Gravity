# Gate 9 — model-break tests

Two deliberately incomplete conventional models are compared with the complete
published field-projection/echo model:

1. Set the effective rotating magnetic projection to zero.
2. Retain the field but omit the spin-echo pi-pulse toggling action.

The resulting chi-squared values are saved in
`outputs/gate_analysis/model_break_tests.json`. These tests show which features
of Figure 5 the conventional model requires; they do not introduce new physics.
