# Gate 8 — null-hypothesis validation

The conventional null is the fitted Eq. (1) spin-echo model plus independent
Gaussian draws whose standard deviations equal the digitized plotted error
bars. Five hundred deterministic-seed Monte Carlo datasets are generated and
refit with that same conventional model. The saved result tests for a biased
ordinary-model residual; it does not claim to model every laboratory
systematic (which the paper does not tabulate).
