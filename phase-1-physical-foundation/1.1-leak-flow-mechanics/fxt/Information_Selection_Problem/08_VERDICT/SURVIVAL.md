## Section 3: Post-Survival Requirements

A framework that reaches SURVIVAL.md has not been confirmed. It has survived the theoretical phase. The next phase is:

1. **Experimental design:** Identify the specific measurement protocol for each prediction
2. **Preregistration:** Submit predictions to a public registry before measurement
3. **Measurement:** Obtain data from observations or experiments
4. **Comparison:** Test predictions against data at specified statistical threshold
5. **Verdict update:** If predictions confirmed, move toward KILL.md for all alternative theories; if predictions falsified, update KILL.md for this framework

SURVIVAL.md being populated means the framework is a serious scientific candidate, not that it is correct.

## Section 4: The Kill Conditions Even After Survival

The framework can still be killed after reaching Gate 7:

- A prediction is measured and falsified
- The derivation is found to contain an assumption-laundering step that was missed
- A new paper demonstrates the primitive is equivalent to an existing proposal (no-boundary, July 2026 paper)
- The primitive is shown to be non-derivable (Gate 5 is retroactively failed)

The adversarial review does not end when the framework survives. It continues through every claim.
