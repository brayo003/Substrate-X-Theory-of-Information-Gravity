## Section 1: The Null Hypothesis

**H₀ (Standard Model Null):** All observational predictions of the framework reduce to predictions already derivable from GR + ΛCDM + inflation + standard model particle physics.

If H₀ cannot be rejected, the framework is consistent with existing data but makes no new predictions. It would be equivalent to ΛCDM with a different theoretical motivation. A framework that is undistinguishable from ΛCDM may have explanatory value (it explains WHY ΛCDM has the parameters it does) but has no testable advantage over ΛCDM.

**The standard required for this program:** H₀ must be rejectable, in principle, by at least one prediction.

---

## Section 2: Parameters of ΛCDM That Can Be "Absorbed"

ΛCDM has free parameters. Any new framework that makes predictions, if those predictions can be absorbed into shifts of ΛCDM parameters, is not distinguishable from ΛCDM.

**Free ΛCDM parameters (Planck 2018 baseline):**
- H₀ (Hubble constant)
- Ω_b h² (baryon density)
- Ω_c h² (cold dark matter density)
- τ (optical depth to reionization)
- n_s (scalar spectral index)
- ln(10^10 A_s) (primordial amplitude)

**Extended parameters (sometimes included):**
- r (tensor-to-scalar ratio)
- n_t (tensor spectral index)
- Ω_k (spatial curvature)
- w (dark energy equation of state)
- N_eff (effective number of neutrino species)
- Σm_ν (sum of neutrino masses)

A prediction is distinguishable from ΛCDM only if:
1. It is not equivalent to a specific value of any existing ΛCDM parameter, AND
2. It predicts a relationship between parameters that ΛCDM treats as independent, OR
3. It predicts a specific non-zero value of a parameter that ΛCDM leaves unconstrained (e.g., specific value of r, specific non-Gaussianity amplitude)

| Large-scale CMB correlations | Low-ℓ angular power spectrum | Sensitive to super-horizon initial conditions |

## Section 4: The Distinguishability Criterion (Formal)

A prediction P from the derived framework is distinguishable from ΛCDM if:

```
∄ (H₀, Ω_b, Ω_c, τ, n_s, A_s, r, ...) ∈ ΛCDM parameter space
such that ΛCDM with those parameters predicts P within 2σ
```

In other words: the prediction cannot be accommodated by any tuning of ΛCDM free parameters.
