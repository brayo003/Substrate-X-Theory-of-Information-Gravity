# UNEXPLAINED_RESIDUALS
## Gate 3 — Formal Statement of Surviving Residuals

---

### Purpose

This document is the Gate 3 output: the formal characterization of what remains unexplained after all standard physics (Gate 2) is granted. Each residual is stated as a precise claim that has no known derivation.

This document can only conclude RESIDUAL EXISTS or NO RESIDUAL for each item. Philosophical dissatisfaction is not a residual. Parametric under-determination is a mild residual. A structural impossibility of explanation is a strong residual.

---

## Section 1: Gate 3 Methodology

A genuine residual requires:
1. A precise physical statement that existing frameworks do not derive
2. The statement is not merely a free parameter (parametric) but a structural gap
3. An adversarial attempt to close it using known physics that demonstrably fails

A non-residual is any claim that is:
- Already explained by some existing framework
- Merely philosophically unsatisfying without a physical gap
- A question of free parameters that could in principle be fixed by future data

## Section 2: Candidate Residual R1 — Low Pre-Inflationary Gravitational Entropy

**Precise statement:** The pre-inflationary gravitational configuration had near-zero Weyl curvature (or equivalently, was near-FLRW in its large-scale geometry). No existing derivation produces this from independent premises.

**Gate 2 status:** 
- GR: does not select low-Weyl initial data
- Inflation: requires it as input (does not derive it)
- No-boundary proposal: claims to derive it but is formally contested
- July 2026 paper: claims to derive it but is explicitly incomplete

**Adversarial closure attempt:**
- Can statistical mechanics close this? No — statistical mechanics has no established entropy for gravitational DOF and would predict high-entropy (high-Weyl) initial state as typical.
- Can inflation close this? No — Penrose's objection stands: inflation requires the smooth pre-inflationary state.
- Can the no-boundary proposal close this? Contested — if accepted, it would close the residual. But it is not established, and Penrose argues it predicts the wrong thing.

**Status: RESIDUAL EXISTS (strong)**

The low pre-inflationary gravitational entropy has no established derivation from independent premises. The candidate proposals (no-boundary, July 2026 paper) are contested or incomplete.

**Important caveat:** If the no-boundary proposal is eventually established to correctly predict low-entropy initial states, this residual is closed. The program must track the no-boundary debate as a live threat to the residual.

## Section 3: Candidate Residual R2 — The Measure Problem

**Precise statement:** The claim that the early cosmological state was "special" or "improbable" requires a well-defined measure on the space of cosmological initial configurations. No such measure is established.

**Gate 2 status:** No framework provides a natural, physically justified measure on the space of all GR initial data. The Liouville measure is not normalizable. Anthropic measures require a multiverse.

**Adversarial closure attempt:**
- Can we define typicality without a measure? In some approaches (constructor theory), possibility/impossibility replaces probability. But even then, the question of which possible states were actualized remains.
- Can we argue the measure doesn't matter if we can derive a selection principle? Yes — if a selection principle is derived that picks out the observed state without reference to any measure, the measure problem is dissolved rather than solved. This would be the ideal outcome of a successful Gate 5.

**Status: RESIDUAL EXISTS (structural) — but dissolve-able by a successful derivation**

## Section 4: Candidate Residual R3 — Primordial Perturbation Amplitude

**Precise statement:** The amplitude of primordial perturbations A_s ≈ 2.1 × 10⁻⁹ is a free parameter in inflation, set by the inflaton potential V(φ) at the time of horizon exit. It is not derived from more fundamental principles.

**Gate 2 status:** Every inflation model that fits the data has A_s as an input. The spectral index n_s is approximately derived from slow-roll conditions, but A_s is not.

**Adversarial closure attempt:**
- Is this just a parameter-fixing problem (mild residual)? Possibly. If a specific inflation model eventually derives A_s from first principles (e.g., from a string landscape calculation), this would close the residual. But currently no such derivation exists.
- Is this a structural gap? Less clear than R1. It is a free parameter in the current framework, not a structural impossibility.

**Status: MILD RESIDUAL (parametric) — lower priority than R1**

## Section 5: Candidate Residual R4 — The Arrow of Time

**Precise statement:** Given symmetric microscopic laws, macroscopic time asymmetry requires a low-entropy initial condition (Past Hypothesis). The Past Hypothesis is assumed, not derived. Why did the universe have a low-entropy initial state from which entropy could increase?

**Relationship to R1:** R4 is downstream of R1. If R1 is resolved (the low-entropy initial gravitational state is explained), R4 may follow — but only if the same mechanism generates temporal asymmetry. This is a hypothesis, not an established connection.

**Status: CONDITIONAL RESIDUAL — depends on the resolution of R1**
