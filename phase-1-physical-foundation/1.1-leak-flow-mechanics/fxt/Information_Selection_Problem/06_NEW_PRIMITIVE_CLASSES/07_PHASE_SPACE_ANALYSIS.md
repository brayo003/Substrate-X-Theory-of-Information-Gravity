## NC-1 — Constraint Propagation

Γ_phys^{NC-1} = {(h,K) ∈ Γ_GR | Cotton-York = 0}

Does Γ_phys^{NC-1} ⊊ Γ_GR?

The Cotton-York tensor Y^{ij} = ε^{ikl}∇_k(K^j_l − (1/3)δ^j_l K). This vanishes for:
- Any K_ij that is uniform (no spatial gradients) — including all homogeneous Bianchi models
- Any K_ij = f(t)h_{ij} (isotropic) — includes FLRW
- Time-symmetric slices (K_ij = 0)

The condition Y^{ij} = 0 is satisfied by a large fraction of cosmologically relevant initial data. It is not satisfied by all data (e.g., gravitational wave data with spatially varying K). So Γ_phys^{NC-1} ⊊ Γ_GR is technically true — but the subset is still large and contains Kasner.

**Outcome: B (weighting-like partial restriction) — Γ_phys ⊊ Γ_GR holds but the subset is not the low-Weyl sector.**
