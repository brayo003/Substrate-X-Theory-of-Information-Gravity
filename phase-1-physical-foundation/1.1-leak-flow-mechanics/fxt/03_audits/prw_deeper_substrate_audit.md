## Part I — Candidate Microscopic Theories

### Candidate D1: Discrete Velocity Boltzmann / BGK Kinetic Theory

**Independent motivation [KR]:** The BGK (Bhatnagar-Gross-Krook) model is a
standard simplification of the Boltzmann equation for dilute gases, independently
motivated by kinetic theory and well-studied since 1954. It has nothing to do
with the PRW a priori.

**Setup:** A one-dimensional gas of particles with velocity set V = {+c, −c}.
The one-particle distribution function f(x, v, t) ∈ ℝ⁺ satisfies:

```
∂f/∂t + v ∂f/∂x = −(f − f^eq) / τ_BGK          [BGK]
```

where f^eq = ρ/2 is the local equilibrium (equal distribution between +c and −c)
and τ_BGK is the relaxation time.

**Well-posedness [KR]:** The BGK equation with two velocities is a first-order
linear hyperbolic system. Well-posedness on ℝ × ℝ⁺ for initial data in L¹ is
classical (Cercignani 1988). Unique mild solutions exist globally in time.

**PRW derivation [T]:**

Define f⁺(x,t) = f(x,+c,t) and f⁻(x,t) = f(x,−c,t). The BGK equation gives:
```
∂f⁺/∂t + c ∂f⁺/∂x = −(f⁺ − (f⁺+f⁻)/2)/τ = −(f⁺−f⁻)/(2τ)
∂f⁻/∂t − c ∂f⁻/∂x = −(f⁻ − (f⁺+f⁻)/2)/τ = +(f⁺−f⁻)/(2τ)
```
Setting λ = 1/(2τ), n⁺ = f⁺, n⁻ = f⁻:
```
∂n⁺/∂t = −c ∂n⁺/∂x − λn⁺ + λn⁻    [M1+]
∂n⁻/∂t = +c ∂n⁻/∂x + λn⁺ − λn⁻    [M1-]
```
This is **exactly** the PRW. No approximation. **The derivation is exact.**

**Assumptions required:**
1. Two-velocity discretisation V = {+c, −c}.
2. BGK relaxation to uniform equilibrium f^eq = ρ/2.
3. Uniform τ_BGK.

**Variables eliminated during coarse-graining:**
None — the two-velocity BGK with this discretisation IS the PRW. The BGK and PRW
are **isomorphic** as dynamical systems: no variables are hidden.

**Richer structure?**
[T] The two-velocity BGK model with V = {+c,−c} and BGK equilibrium has no
additional internal degrees of freedom beyond n⁺ and n⁻. Its state space is
identical to the PRW state space. No structure is discarded. D1 adds no richer
structure to the PRW — it is a different name for the same system.

**Extended field equation:**
D1 reproduces the telegrapher equation exactly. To reproduce the full extended
equation, external force terms must be added (F → biases in f^eq), energy terms
(E → spatially varying τ), and a bulk velocity (v_sub → Galilean frame). These
additions require external inputs — they are not generated by the two-velocity BGK
structure alone.

**Verdict [T D1]:** D1 is mathematically equivalent to the PRW. It does not
constitute a deeper substrate. Candidate rejected as "deeper level."

### Candidate D2: Multi-velocity Lattice Boltzmann (D1Q3, D1Q5)

**Independent motivation [KR]:** Lattice Boltzmann methods (LBM) are independently
motivated as discretisations of kinetic theory, with velocity sets V_N =
{−(N-1)c, ..., −c, 0, +c, ..., +(N-1)c} for N ≥ 3. The D1Q3 model (velocities
{−c, 0, +c}) and D1Q5 model (velocities {−2c, −c, 0, +c, 2c}) are standard LBM
models motivated by hydrodynamics, not by the PRW.

**Setup [KR]:** For D1Q3, the distribution functions are:

```
f_k(x,t) for k ∈ {−1, 0, +1},  velocities v_k = k·c
```

satisfying:
```
∂f_k/∂t + v_k ∂f_k/∂x = −(f_k − f_k^eq(ρ,u)) / τ      [LB-BGK]
```

where f_k^eq(ρ,u) are the Maxwell-Boltzmann equilibrium weights at density ρ
and drift u:
```
f_0^eq = ρ(1 − u²/c²),    f_{±1}^eq = ρ(u²/2c² ± u/2c + ...)
```

**Well-posedness [KR]:** Well-posed as a linear hyperbolic system on the
3-component function space. Global existence and uniqueness in L¹.

**PRW derivation [T D2-PRW]:**

The Chapman-Enskog expansion of D1Q3 BGK to second order in Knudsen number
Kn = τ v / L gives:
- Zeroth order: continuity equation ∂_t ρ + ∂_x (ρ u) = 0.
- First order: momentum equation ∂_t (ρu) + ∂_x(ρu² + ρc²/3) = −(1/τ)ρu.

To obtain the telegrapher equation, one must project to the **momentum-relaxation
subspace** f⁺ − f⁻, not the full distribution. Define:

```
n⁺ = f_{+1},   n⁻ = f_{−1},   n⁰ = f_0  (rest particles)
```

In the limit n⁰ → 0 (removing rest particles, i.e., taking the weight of
f_0^eq → 0): the D1Q3 model reduces to D1Q2 = two-velocity BGK = PRW.

For general n⁰ ≠ 0, the D1Q3 model gives the **diffusion equation** in the
hydrodynamic limit, not the telegrapher equation (the rest-particle mode smooths
out the hyperbolic character).

**[T] Theorem D2-EXACT:** The D1Q3 LBM reduces to the PRW exactly if and only if
the rest-particle weight is set to zero (n⁰ ≡ 0). Otherwise it produces a
diffusion equation with corrections.

**Proof:**
With f_0^eq = 0, the BGK model has f_0 = 0 at all times (if initially zero, the
evolution ∂f_0/∂t = −f_0/τ drives f_0 → 0). The remaining equations for (f_{+1},
f_{-1}) are exactly [M1+] and [M1-] with λ = 1/(2τ). ✓

With f_0^eq ≠ 0, the Chapman-Enskog expansion gives:
```
τ_eff ∂²s/∂t² + ∂s/∂t = D_eff ∂²s/∂x²   where   D_eff = c²τ(1 − 3f_0^eq/ρ)
```
The effective speed D_eff^{1/2} / √τ_eff ≠ c when f_0^eq ≠ 0. The telegrapher
structure is preserved but with renormalised coefficients. ∎

**Variables eliminated during coarse-graining:**
The rest-particle density n⁰(x,t) is eliminated. Its equation is:
```
∂n⁰/∂t = −(n⁰ − f_0^eq(ρ,u)) / τ
```
In the PRW limit (n⁰ ≡ 0), n⁰ carries zero information. In the general D1Q3 case,
n⁰ is a **real scalar field** with its own dynamics.

**[T] Theorem D2-RICH:** The rest-particle density n⁰(x,t) of D1Q3 is a classical
real scalar field. It carries no structure richer than a real scalar — no internal
DOF, no phase variable, no group structure beyond ℝ. When projected out to recover
the PRW, no mathematically richer structure is lost.

**Extended field equation:**
D1Q3 with external force F gives:
```
∂f_k/∂t + v_k ∂f_k/∂x = −(f_k − f_k^eq)/τ + F·∂f_k^eq/∂(ρu)
```
This produces the advection term ∇·(sv_sub) and force term γF in the extended
equation (via Chapman-Enskog). The energy coupling αE requires a temperature-
dependent f_k^eq — an additional assumption.

**Verdict [T D2]:** D1Q3 is a richer model than the PRW, but its extra variable
(rest-particle density n⁰) carries only real scalar structure. The PRW emerges
as an exact limit (n⁰ → 0). D1Q3 is a valid deeper level with one extra variable,
but that variable carries no richer mathematical structure than the PRW itself.

### Candidate D3: Reversible Cellular Automaton — HPP Lattice Gas

**Independent motivation [KR]:** The HPP (Hardy-Pomeau-de Pazzis, 1973) lattice
gas is the first reversible cellular automaton model of a fluid, independently
motivated as a discrete Hamiltonian system. Its dynamics consists of free streaming
and local reversible collisions, with no dissipation built in.

**Setup [KR]:** On a 1D lattice with sites i ∈ ℤ and time steps n ∈ ℤ:
- Each site has occupation numbers η_i^σ ∈ {0,1} for σ ∈ {+1,−1}.
- Streaming: η_{i+σ}^σ(n+1) ← η_i^σ(n) (particles move one step in direction σ).
- Collision rule (1D HPP): η_i^+(n) and η_i^−(n) exchange if both sites are occupied
  (reversible bounce-back). Formally: if η_i^+ = η_i^− = 1, they remain (no collision
  in 1D HPP, or bounce back depending on variant).

**Well-posedness [KR]:** The HPP automaton is a deterministic invertible map on
{0,1}^{2L}. Exact solutions exist for all initial conditions.

**PRW derivation [T D3-PRW]:**

Define the ensemble-averaged densities:
```
n⁺(x,t) = ⟨η_i^+(n)⟩,   n⁻(x,t) = ⟨η_i^-(n)⟩
```
In the molecular chaos (Boltzmann) approximation (assuming statistical independence
of occupation numbers at different sites):
```
⟨η_i^+ η_i^-⟩ ≈ ⟨η_i^+⟩⟨η_i^-⟩ = n⁺ n⁻
```
The collision rule creates a nonlinear coupling term n⁺n⁻. In the **low-density
limit** (n± ≪ 1) and with a stochastic collision rule (replacing deterministic
bounce-back with a Poisson-rate reversal), the linearised equation becomes:
```
∂n⁺/∂t = −c∂n⁺/∂x − λn⁺ + λn⁻
∂n⁻/∂t = +c∂n⁻/∂x + λn⁺ − λn⁻
```
which is [M1±]. **The derivation is asymptotic** (requires low-density + molecular
chaos + stochastic collision rule).

**[T] Theorem D3-ASYM:** The PRW is an asymptotic, not exact, consequence of the
HPP automaton. The exact lattice gas dynamics contains nonlinear collision terms
O((n±)²) that vanish only in the low-density limit.

**Variables eliminated during coarse-graining:**
1. **Microscopic fluctuations** δη = η − ⟨η⟩: deviations of occupation numbers
   from their means. These are real-valued stochastic variables.
2. **Correlations** ⟨η_i^+ η_j^-⟩ for i≠j: pair correlations across sites.
3. **Boolean occupation structure**: the constraint η ∈ {0,1} (Fermi statistics).

**[T] Theorem D3-BOOL:** The Boolean occupation structure η ∈ {0,1} of the HPP
automaton is a non-trivial mathematical constraint that does not survive in the
PRW limit. Specifically:

- The PRW densities n±(x,t) ∈ [0,∞) are real-valued (unbounded from above after
  scaling); the Boolean constraint is lost in the continuum limit.
- The Boolean algebra 𝔹 = {0,1}² per site has a natural GL(2,𝔽₂) symmetry
  (invertible linear maps over 𝔽₂). This symmetry group is finite and discrete.
  In the continuum limit, the relevant symmetry becomes the Z₂ exchange symmetry
  of the PRW — a strict reduction.

**Richer structure?**
[T] The discarded variables (microscopic fluctuations, correlations, Boolean
constraint) are richer than the PRW in the following senses:
- The Boolean constraint encodes an exclusion principle not present in the PRW.
- The pair correlations encode spatial correlations across sites, absent from the
  mean-field PRW.
- These structures are, however, classical: no complex phases, no non-commutativity,
  no continuous symmetry groups beyond ℝ.

**[T] Theorem D3-RICH:** The structures discarded during coarse-graining from HPP
to PRW are: (a) short-range spatial correlations (2-point functions), (b) Boolean
exclusion constraints. Both are classical structures, richer than the PRW in the
sense of containing more information, but not richer in the algebraic sense
(no non-commutative algebra, no continuous internal symmetry group, no fibre bundle).

**Verdict [T D3]:** HPP is an independently motivated, well-defined discrete
microscopic theory from which the PRW emerges asymptotically. The discarded
variables carry classical richer structure (correlations, exclusion), but no
non-commutative or phase-carrying structure.

### Candidate D4: Classical Klein-Gordon Field Theory

**Independent motivation [KR]:** The Klein-Gordon equation
`(∂²_t − c²∂²_x + m²)φ = 0` is a Lorentz-invariant hyperbolic PDE independently
motivated as the classical field equation for a relativistic scalar field with
mass m. It predates quantum mechanics (Klein 1926 was a re-derivation; the
classical wave equation version is due to de Broglie 1924).

**Setup:** Real scalar field φ(x,t) ∈ ℝ on ℝ × ℝ⁺ satisfying:
```
∂²φ/∂t² − c²∂²φ/∂x² + m²φ = 0                [KG]
```

**Well-posedness [KR]:** The Klein-Gordon equation is a linear hyperbolic PDE.
The Cauchy problem with (φ(x,0), ∂_t φ(x,0)) ∈ H¹(ℝ) × L²(ℝ) has a unique
global solution. Energy E = ½∫(|∂_t φ|² + c²|∂_x φ|² + m²|φ|²) dx is conserved.

**PRW derivation attempt [T D4-FAIL]:**

The Klein-Gordon equation is second-order in time and space. Define:
```
s = φ² + (∂_t φ)²/(m² + c²k²)   (local energy density, mode-by-mode)
```
The energy of a mode with wavenumber k satisfies:
```
∂²_t E_k + (m² + c²k²) E_k = 0   (undamped oscillation)
```

This is a **conservative, undamped** system. There is no damping term −J/τ.
The telegrapher equation has a damping term; the Klein-Gordon equation does not.

**[T] Theorem D4-NO-DAMP:** The classical Klein-Gordon field does not directly
produce the telegrapher equation. It produces an undamped wave equation (m=0)
or a dispersive equation with mass gap (m>0), neither of which has the
irreversibility term ∂_t s required by the PRW.

**Proof:** The Klein-Gordon equation with real φ is self-adjoint and conserves
energy. Its solutions do not decay in L² norm. The telegrapher equation
`τ∂²_t s + ∂_t s = c²τ∂²_x s` has exponentially decaying homogeneous solutions
(damping rate 1/τ). These are incompatible: the KG field cannot produce damping
without coupling to an additional dissipative sector. ∎

**Can PRW emerge indirectly?**

[T] The Klein-Gordon field coupled to a dissipative bath (Caldeira-Leggett)
does reduce to the PRW via the Mori-Zwanzig projection — but this is the R1
embedding already classified. The Klein-Gordon field itself is not a deeper substrate
for the PRW without the bath.

**Variables eliminated:**
If one couples KG to a bath and projects, the bath variables are eliminated
(as in R1). The KG field itself has one conserved current:
```
j_μ = φ ∂_μ φ   (for real field — this is a real current, not U(1))
```
The real-field KG has no U(1) symmetry (only Z₂: φ → −φ). The complex KG
field has U(1) symmetry, but introducing complex φ requires new assumptions
(complex-valued field).

**Richer structure of discarded variables?**

[T] For real KG: the only discarded variable in any coupling-to-bath construction
is the bath itself (same structure as R1). The KG field alone adds only the
standing-wave structure of the KG dispersion ω² = c²k² + m². This is a real
scalar structure.

[T] For complex KG: the field ψ = φ₁ + iφ₂ ∈ ℂ has a U(1) conserved charge
Q = ∫Im(ψ* ∂_t ψ) dx. This phase variable is a **genuinely new structure**
absent from the real PRW. However, introducing complex φ is an external assumption,
not derived from the PRW.

**Verdict [T D4]:** The real Klein-Gordon field does not produce the PRW directly
(no damping). It is a deeper level only via bath coupling (=R1). The complex KG
field introduces a U(1) phase variable — richer structure — but requires an
external assumption (complex-valued field). No deeper purely classical
motivation exists.

### Candidate D5: Hamiltonian Particle System on 1D Lattice (FPUT Chain)

**Independent motivation [KR]:** The Fermi-Pasta-Ulam-Tsingou (FPUT) chain is a
Hamiltonian system of N particles on a 1D lattice with nearest-neighbour coupling:
```
H = Σᵢ [pᵢ²/(2m) + V(qᵢ₊₁ − qᵢ)]
```
where V(r) = kr²/2 + αr³/3 + βr⁴/4 (harmonic + anharmonic). The harmonic case
(α=β=0) is exactly solvable. The FPUT system is independently motivated as a
model of lattice vibrations (phonons) in solids.

**Well-posedness [KR]:** For the harmonic chain, H is quadratic; equations of
motion are linear second-order ODEs. Well-posed globally. For anharmonic terms,
local existence and uniqueness hold by standard ODE theory.

**PRW derivation from harmonic chain [T D5-PRW]:**

For the harmonic chain, the normal modes are phonons. The acoustic dispersion
relation is ω(k) = 2√(K/m) |sin(k/2)| ≈ c|k| for small k, with c = √(K/m) · lattice spacing.

The one-phonon distribution function g(k, t) satisfies (in the kinetic limit):
```
∂g/∂t + v_g(k) ∂g/∂x = −(g − g^eq)/τ_ph
```
where v_g = dω/dk is the group velocity and τ_ph is the phonon relaxation time.
For the two-velocity approximation v_g ≈ ±c:
```
∂n⁺/∂t + c∂n⁺/∂x = −(n⁺−n⁻)/(2τ_ph)
∂n⁻/∂t − c∂n⁻/∂x = +(n⁺−n⁻)/(2τ_ph)
```
This is [M1±]. **The derivation is asymptotic** (requires long-wavelength,
two-velocity approximation, and Markov relaxation for τ_ph).

**Variables eliminated during coarse-graining:**

1. **Short-wavelength phonon modes** (wavenumbers k near the Brillouin zone boundary
   |k| ~ π/a): these are acoustic modes with non-linear dispersion and are projected
   out in the long-wavelength limit.
2. **Phase information of phonon modes**: each phonon mode k has a complex amplitude
   A_k = |A_k| e^{iφ_k}. The phase φ_k ∈ [0,2π) is eliminated when taking the
   occupation number n(k) = |A_k|².
3. **Spatial correlations** ⟨A_k A_{k'}*⟩ for k≠k': off-diagonal correlators that
   encode coherence between modes. These are projected out in the Boltzmann limit.

**[T] Theorem D5-PHASE:** The phonon mode amplitudes A_k ∈ ℂ carry a U(1) phase
φ_k = arg(A_k) ∈ [0,2π). This phase is eliminated when computing the occupation
number n_k = |A_k|². The elimination map:

```
π: ℂ^{N/2} → ℝ^{N/2}_+,   (A_k) ↦ (|A_k|²)
```

is many-to-one with fibre U(1)^{N/2}: for each occupation number (n_k), there
are uncountably many phase configurations (φ_k) that give the same n_k.

**[T] Theorem D5-RICH:** The discarded phase variables φ_k carry the following
mathematical structure:
- They parametrise the torus 𝕋^{N/2} = U(1)^{N/2} (a compact Lie group/manifold).
- The torus 𝕋^{N/2} is a non-trivial fibre over the occupation-number base ℝ^{N/2}_+.
- The fibration π: ℂ^{N/2} → ℝ^{N/2}_+ has the structure of a principal U(1)^{N/2}-bundle.
- This structure is absent from the PRW: the PRW fields n±(x,t) are real-valued
  and carry no phase fibre.

**Proof:**
The harmonic chain equations of motion are:
```
A_k(t) = A_k(0) e^{-iω(k)t}   (free oscillation)
```
The phase φ_k(t) = φ_k(0) − ω(k)t evolves as a linear flow on the torus 𝕋^{N/2}.
The occupation number n_k = |A_k|² is constant (conserved). The projection
n_k = |A_k|² is a standard Hopf fibration structure: S^{2N-1} → ℂP^{N-1} (for
fixed total amplitude). For independent modes, the fibration is 𝕋^{N/2} as stated. ∎

**Extended field equation:**
The harmonic chain produces the free telegrapher (no forcing terms). The
anharmonic terms produce phonon-phonon scattering, which generates the irreversible
term −σ_irr and an effective relaxation rate τ = τ_ph. The energy-coupling terms
αE and β∇·(Ev_sub) can be generated by including an energy density E and
coupling constants α, β via phonon-mediated scattering.

**[T] Theorem D5-EXT:** The phonon kinetic equation for the anharmonic FPUT chain
in the long-wavelength, two-velocity limit produces the extended field equation:
```
τ∂²s/∂t² + ∂s/∂t = c²τ∂²s/∂x² − ∇·(sv_sub) + γF − σ_irr
```
with:
- τ = τ_ph (phonon relaxation time)
- c = acoustic speed
- σ_irr from phonon-phonon scattering (anharmonic)
- γF from external forces
- ∇·(sv_sub) from lattice drift v_sub

The terms αE and β∇·(Ev_sub) require energy-phonon coupling which the FPUT chain
provides via the anharmonic terms (α ~ β ~ anharmonicity / temperature).

**Verdict [T D5]:** The FPUT harmonic/anharmonic chain is an independently
motivated Hamiltonian lattice system from which the PRW emerges asymptotically.
Crucially, the discarded phonon phase variables φ_k ∈ U(1) form a principal
U(1)^{N/2}-bundle over the PRW state space — a genuinely richer geometric structure
that is irreversibly eliminated by the coarse-graining map n_k = |A_k|².

### Candidate D6: Stochastic Lattice Gas with Detailed Balance

**Independent motivation [KR]:** Stochastic lattice gases (SLG) with detailed
balance are standard models in non-equilibrium statistical mechanics (Liggett 1985,
Spohn 1991), independently motivated as models of interacting particle systems.
They have rigorous mathematical foundations in the theory of Markov processes.

**Setup:** State space Ω = {0,1}^{2ℤ} (right/left-mover occupations per site).
Evolution: continuous-time Markov chain with generator:
```
(L f)(η) = Σ_x [c_{x,+}(η)(f(η^{x,+}) − f(η)) + c_{x,−}(η)(f(η^{x,−}) − f(η))]
```
where η^{x,σ} denotes the configuration with the occupation at (x,σ) flipped,
and c_{x,σ}(η) are jump rates satisfying detailed balance:
```
μ(η) c_{x,σ}(η) = μ(η^{x,σ}) c_{x,σ}(η^{x,σ})
```
for an invariant measure μ.

**Well-posedness [KR]:** Stochastic lattice gases with bounded rates are well-posed
Markov processes. Existence and uniqueness of the process and its invariant measure
are classical results (Liggett 1985).

**PRW derivation [T D6-PRW]:**

In the hydrodynamic scaling limit (Spohn 1991): rescale x → x/ε, t → t/ε²,
and take ε → 0. For a specific class of rates (exclusion process with drift), the
macroscopic density ρ(x,t) satisfies:
```
∂ρ/∂t = ∂_x [D(ρ) ∂_x ρ − χ(ρ)]   [HYDRO]
```
This is a nonlinear diffusion equation — **parabolic**, not hyperbolic.

To obtain the telegrapher equation (hyperbolic), one must use the **mesoscopic
scaling** (Kac 1974, Goldstein 1951): rescale x → x/ε, t → t/ε (not t/ε²).
In the mesoscopic limit, the stochastic lattice gas with two species and
small reversal rate λε gives:
```
∂n⁺/∂t = −(c/ε) ∂n⁺/∂x − λn⁺ + λn⁻
∂n⁻/∂t = +(c/ε) ∂n⁻/∂x + λn⁺ − λn⁻
```
In the ε → 1 limit (keeping c and λ fixed): this is exactly [M1±]. **Exact in
the mesoscopic limit.**

**Variables eliminated:**

1. **Microscopic fluctuations** (the stochastic noise η − ⟨η⟩).
2. **Pair correlations** ⟨η_{x,+} η_{y,−}⟩ (two-site correlators).
3. **Higher cumulants** of the occupation statistics.

**[T] Theorem D6-CORR:** The pair correlation function G₂(x,y,t) = ⟨η_{x,+} η_{y,−}⟩
satisfies its own evolution equation (the BBGKY hierarchy for SLG). This equation
involves three-point correlations G₃, which involve G₄, etc. The full hierarchy is
richer than the PRW: it contains an infinite tower of correlation functions.

**[T] Theorem D6-RICH:** The structure discarded by the hydrodynamic/mesoscopic
limit of the SLG is the full correlation hierarchy {G₂, G₃, ...}. This is an
infinite-dimensional structure (a sequence of functions of increasing numbers of
variables). Its mathematical content is:
- Real-valued correlation functions (classical).
- A graded algebra structure (the algebra of cumulants under convolution).
- No complex phases, no non-commutativity.

**Verdict [T D6]:** SLG is a valid deeper level producing the PRW asymptotically.
The discarded variables are an infinite correlation hierarchy — richer than the
PRW in information content but classical in algebraic structure.

### Candidate D7: Hyperbolic System of Conservation Laws (Friedrichs System)

**Independent motivation [KR]:** Friedrichs symmetric hyperbolic systems
(Friedrichs 1954) are independently motivated as the most general first-order
PDE systems that are well-posed and causal. They encompass Maxwell's equations,
elasticity, and linear acoustics.

**Setup:** A general first-order symmetric hyperbolic system on ℝ^n:
```
A₀ ∂_t u + Σ_j A_j ∂_j u = Bu + f         [FRIED]
```
where u: ℝ × ℝ⁺ → ℝ^N, A₀, A_j are symmetric matrices with A₀ positive definite,
and B is a dissipation matrix.

**Well-posedness [KR]:** Friedrichs (1954): For smooth coefficients and initial
data in H^s (s > d/2+1), the system [FRIED] has a unique classical solution
globally if B is dissipative (⟨Bu,u⟩ ≤ 0).

**PRW as Friedrichs system [T D7-PRW]:**

The PRW [M1±] is a 2-component Friedrichs system with N=2, u = (n⁺, n⁻):
```
∂_t u + A ∂_x u = Bu
```
where:

**[T] Theorem D7-UNIQUE:** Within the class of 2×2 symmetric hyperbolic systems

**Proof:** The most general 2×2 A satisfying: (i) symmetry; (ii) eigenvalues ±c;
