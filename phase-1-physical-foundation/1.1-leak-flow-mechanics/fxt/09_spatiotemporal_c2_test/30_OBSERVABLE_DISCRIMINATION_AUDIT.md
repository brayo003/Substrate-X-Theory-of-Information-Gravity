## 1. Executive Verdict

The C2 quantum layer, as currently formulated, does **not** contain an experimentally
accessible observable that is mathematically distinguishable from conventional
Ornstein-Uhlenbeck (OU) colored noise in any parameter regime accessible with
current hardware.

Three conditional discriminators exist in principle. All three are currently blocked:

| Discriminator | Condition to be useful | Blocked by |
|---------------|----------------------|------------|
| K0 vs exp spatial shape | ξ_c < chip size | c is a free parameter; ξ_c >> chip |
| ξ_c/τ_B = 2c constant with T | Variable-T platform + both observables | No T-variable QPU access |
| Non-Gaussianity (κ_3) | N_particles ~ O(1) | N_particles not specified in C2 |

The deepest blocker is not experimental — it is theoretical: **c is a free parameter in C2**
(confirmed in 00_THEORY_AUDIT.md GAP-7). Without an independently derived value of c,
the joint test c = ξ_c/(2τ_B) is circular, and the shape test cannot be targeted.

## 3. Conventional Null Model Structure

```
dJ/dt = −J/τ_ou + η(t),   ⟨η(t)η(t')⟩ = σ²δ(t−t')
C_JJ(t) = σ²τ_ou · exp(−|t|/τ_ou)
S_JJ(ω) = 2σ²τ_ou / (1 + ω²τ_ou²)   [same Lorentzian]
Φ(t) = Γ·τ_ou·[t/τ_ou − 1 + exp(−t/τ_ou)]   [IDENTICAL to EXACT-PHI]
```

Free parameters: {τ_ou, σ²} — independently assignable (no structural relation)
Spatial correlation: can be assigned independently as exp(−r/ξ_ou) with ξ_ou free

### 3.B Quasistatic Gaussian noise

```
C_JJ(t) = S₀   (t-independent, τ_B → ∞)
Φ(t) = Γ·t²/(2τ_B)   [Gaussian decay]
S_JJ(ω) = 2πS₀·δ(ω)   [DC component only]
```

Distinguishable from C2/OU: YES (different decay shape, detectable by DD)

### 3.C White/Markovian noise

```
C_JJ(t) = S₀·δ(t)   (τ_B → 0)
Φ(t) = Γ_Markov·t   [exponential coherence]
S_JJ(ω) = S₀   [flat spectrum]
```

Distinguishable from C2/OU: YES (exponential vs non-exponential Ramsey shape)

### 3.D Stretched-exponential phenomenology

```
C(t) = exp(−(t/T_S)^β)   [β ∈ (0,2]]
```

β = 1: exponential; β = 2: Gaussian; 1 < β < 2: intermediate
Distinguishable from C2: YES when β is inconsistent with 1 (Markov) or 2 (static)
but NOT from OU (OU can produce same stretched-exp behavior with mixed τ_B distribution)

### 3.E Spatially correlated Gaussian noise (general)

```
C_JJ(r, t) = f(r) · g(t)
g(t) = exp(−t/τ_b)   [same OU]
f(r) = exp(−r/ξ_ou)  [free spatial function]
```

Free parameters: {τ_b, ξ_ou} independently assignable.
This model can reproduce ANY combination of measured (τ_B, ξ_c) by tuning two free
parameters — identical predictive power to C2 but with zero structural constraint.

## 5. Higher-Order Cumulant Analysis

### 5.1 Why EXACT-PHI implies Gaussianity

The derivation of EXACT-PHI uses the second-order cumulant expansion:

```
⟨exp(iφ)⟩ = exp(−⟨φ²⟩/2)   [exact iff noise is Gaussian]
```

This is **exact** if and only if the noise J(t) is a Gaussian process. By using EXACT-PHI
as the C2 prediction, the theory has implicitly assumed Gaussian noise at the
observable level. Therefore, by construction, C2 has no non-Gaussian signatures at
the level of the coherence function.

### 5.2 Non-Gaussianity from the discrete PRW

The PRW generates J(t) as a sum of N_particles independent walkers. By the Central
Limit Theorem:

```
κ_3[φ(T)] / κ_2[φ(T)]^(3/2) ~ 1/√N_particles
κ_4[φ(T)] / κ_2[φ(T)]²      ~ 1/N_particles
```

Non-Gaussianity exists but is suppressed by the number of substrate particles.

**Numerical confirmation (p25 Test 5):**

| N_particles | Skewness (measured) | Expected (~1/√N) |
|------------|--------------------|--------------------|
| 1           | 0.019               | ~1.0               |
| 5           | 0.013               | ~0.45              |
| 100         | 0.014               | ~0.10              |
| 1000        | 0.014               | ~0.03              |

The numerical skewness is consistent with CLT suppression at rate 1/√N_particles.

### 5.3 Why this does not help

1. The C2 theory does not specify N_particles. A macroscopic substrate has
   N_particles >> 1 and is Gaussian to all practical purposes.

2. Even if N_particles ~ 1 were established, detecting κ_3 ~ 0.02 requires
   ~(0.02)^{-2} ~ 2,500 independent phase samples per qubit per delay point.
   That is achievable (~10⁴ shots). But N_particles ~ 1 is not a C2 prediction
   — it is a specific physical scenario not derived from the theory.

3. The non-Gaussianity is a generic property of any discrete-particle noise
   source (e.g., telegraph noise, single TLS defects). It is not C2-specific.

**Verdict: Non-Gaussianity is a CONDITIONAL discriminator that requires
N_particles ~ O(1) AND that N_particles ~ O(1) is itself a C2 prediction.
Neither condition is currently established.**

## 6. Multi-Time Correlation Analysis

### 6.1 Two-time coherence

Both C2 and OU have the same two-time correlation:

```
⟨J(t)J(t')⟩ = S₀·exp(−|t−t'|/τ_B)
```

This uniquely determines the Gaussian process up to second order (Bochner's theorem).
All two-time observables (Ramsey, Hahn echo, CPMG, PSD, CSD) are non-discriminating.

### 6.2 Three-time coherence

For a Gaussian process, the connected three-point function vanishes identically:

```
⟨J(t1)J(t2)J(t3)⟩_c = 0   [Wick's theorem for Gaussian processes]
```

Both C2 (in the Gaussian/CLT limit) and OU satisfy this. No three-time observable
distinguishes them.

### 6.3 The ratio R(t1,t2) = C(t1+t2)/(C(t1)·C(t2))

This ratio differs from 1 in the non-Markovian regime (p25 Test 7 confirms values
of 0.31–0.78 for t/τ_B ~ 1–4). But both C2 and OU give the **same** R(t1,t2)
formula since Φ(t) is identical. This observable distinguishes non-Markovian from
Markovian behavior — not C2 from OU.

**Verdict: Multi-time correlations are NON-DISCRIMINATING for C2 vs OU.**

## 7. Dynamical-Decoupling Analysis

### 7.1 The filter-function framework

Under any DD sequence with filter function F(ω, t), the coherence decay is:

```
−ln|C(t)| = (1/π) ∫₀^∞ S_J(ω) F(ω,t) dω
```

Since S_J^C2(ω) = S_J^OU(ω) = Lorentzian(ω_c, S₀), **every DD sequence
gives the same coherence for C2 and OU.** This includes:

- Ramsey (free induction decay)
- Hahn echo
- CPMG-n (all n)
- Uhrig dynamic decoupling
- XY-n sequences
- Any arbitrary pulse sequence

**Numerical confirmation (p25 Test 4):** Ramsey Φ and Hahn Φ match to < 0.1%
between the numerical filter-function integral and EXACT-PHI.

### 7.2 What DD sequences CAN discriminate

DD can distinguish:
- C2/OU (Lorentzian) from white noise (flat): yes
- C2/OU (Lorentzian) from quasistatic (1/f²): yes
- C2/OU from 1/f noise: yes (different rolloff)
- C2/OU from multi-Lorentzian: only with sufficient frequency coverage

**But C2 vs OU: NO — identical Lorentzian → identical DD response.**

## 8. Spatiotemporal Analysis

### 8.1 The K₀ vs exponential shape distinction

The 2D C2 prediction is K₀(r/ξ_c) (from 02_2D_CORRELATION_DERIVATION.md).
The OU spatial model is exp(−r/ξ_c) (standard exponential).

**These are mathematically different functions.** At d ~ ξ_c, they differ by ~20-40%.
The AUC for distinguishing them is near 1.0 when ξ_c ~ chip size (p25 Test 11).

**The problem:** At the C2-injected parameters (c = 10⁴ m/s, τ_B = 5 µs):

```
ξ_c = 2 × 10⁴ × 5×10⁻⁶ = 0.1 m = 10 cm
chip max separation = 632 µm
d/ξ_c = 0.006
```

At d/ξ_c = 0.006, K₀(0.006) ≈ 5.2 and K₀(0.012) ≈ 4.5 — but
**normalized to K₀(a/ξ_c = 0.002)**, both K₀ and exp give values indistinguishable
from 1.0 at all measured separations.

The shape test becomes viable only when ξ_c < ~2 × d_max ~ 1.2 mm.
This requires c < 120 m/s — a value not predicted by C2 theory.

### 8.2 The ξ_c = 2cτ_B constraint revisited

This relation is **necessarily true** in C2 (derived from the PRW parameters v, λ).
It is **optionally true** in OU (OU can independently assign τ_B and ξ_c).

A genuine test would be: measure τ_B and ξ_c independently, compute
c = ξ_c/(2τ_B), verify it is constant across all qubits and conditions.

**The blocker:** c is a free parameter in C2. If we fit c from the data, the
consistency check is circular. OU with the same free parameter c would pass
the same test.

**For the test to have discriminating power:** C2 must predict c independently
from something other than ξ_c and τ_B measurements.

### 9.2 Classification

```

```

This is not a gap that can be fixed by a better experiment. It is a theoretical

### 9.3 Consequence for discriminability

Without an independent prediction of c:
- The joint test c = ξ_c/(2τ_B) is a measurement, not a test
- Any measured value of c is consistent with C2 (c is a free parameter)

- The test cannot falsify either model

**If C2 derived c from first principles** (e.g., c = substrate phonon speed / factor),
then the joint test becomes: "does measured c match predicted c?" — a genuine test.
Without this, the test is an underdetermined parameter estimation.

## 13. Failure Modes

### 13.1 Structural degeneracy (fundamental)

C2 and OU are observationally equivalent because C2 derives its coherence function
from an OU process (the PRW current at a point). This is not an accident —
it is a mathematical consequence of the PRW's local stochastic structure.
No improvement in hardware, shot counts, or measurement precision can resolve it.

### 13.2 Free parameter c (theoretical)

The substrate speed c is not independently constrained by C2. Until it is, the
one potentially discriminating observable (ξ_c = 2cτ_B) cannot be tested.

### 13.3 Unspecified N_particles (theoretical)

The non-Gaussian correction scales as 1/√N_particles but N_particles is not
specified by the theory. This makes non-Gaussianity a conditional claim, not
a prediction.

### 13.4 A-BRIDGE-τ not proven (theoretical)

The identification τ_B = τ = 1/(2λ) is an open assumption (GAP-3 in 00_THEORY_AUDIT).
If τ_B ≠ τ, the temporal observable decouples from the spatial observable and
the joint test is further undermined.

### 13.5 1D/3D dimensional inconsistency (theoretical)

The PRW derivation is 1D. The rotational variance formula uses 3D isotropy. The
spatial correlator is derived for 2D. The IBM chip is 3D. These are not reconciled.

## 14. What Would Actually Falsify C2

C2 would be **falsified** if an experiment found:

1. ξ_c measured on chip AND τ_B measured from Ramsey AND the ratio ξ_c/τ_B
   violates ξ_c = 2cτ_B for all c — impossible unless c is independently predicted.

2. The spatial correlator shape is clearly NOT K₀ when ξ_c ~ chip size.
   This requires a platform where d/ξ_c ~ 0.1–10, which requires c to be independently
   predicted and small enough for ξ_c ~ mm.

3. If C2 predicts a temperature dependence τ_B(T) ~ T^{−n} (from phonon-bath
   reversal rate), and measurement finds a different scaling.

4. A non-Markovian parameter NMP >> 1 with a measured Ramsey shape that is NOT
   consistent with EXACT-PHI — but consistent with some other functional form.
   This would falsify the OU/C2 class of models together, not C2 specifically.

**Currently, none of these tests can be constructed because c is free and
no temperature-variable platform is accessible.**

## 15. What Would Actually Support C2 Over OU

C2 would be **genuinely supported** (not merely compatible) if:

1. C2 derives c independently from PRW parameters (e.g., from phonon speed,
   from the FPUT-PRW correspondence, from the quantum information gravity scale).
   Then measuring c_measured = ξ_c/(2τ_B) and finding c_measured = c_predicted
   within uncertainty would support C2.

2. The spatial shape K₀(r/ξ_c) is confirmed to fit better than exponential exp(−r/ξ_c)
   with ΔBIC > 6 on a platform where d/ξ_c ~ 1–3.

3. The ratio ξ_c(T)/τ_B(T) is measured at multiple temperatures and found to be
   temperature-independent, consistent with c = const (the C2 prediction)
   while inconsistent with an OU model where the two parameters are independent.

4. The non-Gaussianity κ_3/κ_2^{3/2} is measured to be non-zero and consistent
   with the value expected for the C2 substrate particle count N_particles,
   where N_particles is independently derived from the substrate energy density.

**None of these are achievable without first-principles theoretical progress on c.**

## 17. Final Project Decision

### Verdict: **C — C2/OU IDENTIFIABILITY FAILURE — THEORY REQUIRES REVISION**

The C2 quantum layer contains **no currently accessible observable** that is
mathematically distinguishable from a conventional OU colored-noise bath.

This is not a hardware limitation. It is a theoretical property of the model:
the PRW generates an OU process at the observable level. The full taxonomy of
observable discrimination tests (11 tests, p25) confirms this in every case.

Three conditional discriminators exist but all require theoretical progress first:

**Priority 1 (highest impact):** Derive c from C2 first principles.
If c is independently predicted, the joint test ξ_c = 2cτ_B becomes executable
and falsifiable. This is a theoretical task, not an experimental one.

**Priority 2:** Derive N_particles from the C2 substrate energy/entropy density.
If N_particles can be predicted, the non-Gaussianity test becomes a C2-specific
prediction rather than a conditional claim.

**Priority 3 (low):** Prove A-BRIDGE-τ (τ_B = 1/(2λ)) formally.
This closes a logical gap but does not by itself create a new discriminator.

### On the project freeze

The quantum branch should remain **FROZEN** in its experimental form.
The correct next step is theoretical, not experimental:

> Derive c_C2 from PRW parameters without reference to ξ_c or τ_B measurements.

If this derivation succeeds and gives c ~ 10²–10³ m/s, a concrete experiment
becomes possible on a large superconducting chip (if IBM or equivalent access
becomes available). If the derivation is impossible within C2, the quantum layer
is permanently non-falsifiable in the Ramsey/dephasing channel.
