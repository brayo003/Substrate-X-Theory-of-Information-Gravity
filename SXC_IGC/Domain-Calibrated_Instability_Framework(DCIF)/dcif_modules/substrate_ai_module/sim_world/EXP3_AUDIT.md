## 2. EXP2 defects addressed in EXP3

### Defect A — Hard coordination gate (Critical)

`AgentState.decide()` contained:
```python
if obs.coord_task_active:
    if coord_cap > threshold ...: return "cooperate"
```
This meant cooperation was impossible without an explicit task announcement.
The substrate could only modulate threshold *within* the gate, never open it.

**EXP3 fix:** Remove `coord_task_active` from `TickObservation`. Use probabilistic
policy: `P(cooperate) = coord_cap = 0.5*(1+c_spectral)`. Agents cooperate
independently on each tick based solely on substrate signal and own state.

### Defect B — Future information in ablations (Critical)

Time-reversed and constant ablations used signals from the full run (including
future ticks) computed in a reference pre-run before the trial.

**EXP3 fix:** All ablations are strictly online. At tick t, only signals from
ticks 0..t are accessible.

### Defect C — Weak coupling signal (High)

After coordination success, mean Δc_spectral = −0.0016 (barely above noise).
Coordination events did not produce a reliably detectable field signature.

**EXP3 fix:** Keep coherent perturbation but test at tau=2.0 where Δ per
precursor injection ≈ +0.11 (8× larger than EXP2 effect). Optionally increase
perturbation amplitude if stability tests pass.

### Defect D — Ceiling effect (High)

37–50% of EXP2 trials achieved CCR=1.0. Insufficient dynamic range.

**EXP3 fix:** Probabilistic policy + min_coord=4 + no gate gives baseline
CCR ≈ 22% at signal=0 (theoretical 18.75% from binomial, empirical ~22%).
Task window=3 raises this to ~44%. Pilot calibration determines final window.

## 3. New components required

### Environmental precursor mechanism

**Physics basis:** An independent external event injects a narrow Gaussian
perturbation (width=1.5m) at a fixed zone 3–8 ticks before a coordination
task fires. This pushes high-k fluctuation power into the field. At tau=2.0,
this produces Δc_spectral ≈ +0.11 that persists for 8+ ticks.

**Independence from agents:** Precursor events are generated by a separate RNG
stream (seed+5000). They are applied directly to the physical field, not through
any agent action. Agents cannot observe precursor identity or future consequence.

**Causal chain:**
```
rng_precursor → precursor event at tick t_p
→ apply_perturbation(field, precursor_zone, 5.0, 1.5)
→ field evolves → high-k modes increase → C_spectral rises
→ agent observes C_spectral (not precursor label)
→ agent adjusts cooperation probability
→ task fires at tick t_p + precursor_lead
→ coordination succeeds or fails
```

**Four event types (required for TP/FP/TN/FN measurement):**
- Type A: Precursor + coordination task (TP opportunity)
- Type B: Coordination task with no precursor (FN opportunity)
- Type C: Precursor with no subsequent task (FP opportunity)
- Type D: Neither (TN opportunity)

### Online ablations (7 conditions total)

1. **baseline** — signal=0.0 always
2. **spectral** — actual C_spectral from field
3. **online_shuffled** — at tick t, draw uniformly from history[0..t]
4. **online_delayed** — supply c_spectral from tick max(0, t-k), k=5
5. **running_mean** — mean of c_spectral[0..t] (causal running mean)
6. **precursor_only** — disable agent-to-field perturbations; keep precursor; enables environmental sensing isolation
7. **feedback_only** — disable precursor events; keep agent perturbations; enables feedback reinforcement isolation

### Probabilistic policy (replaces deterministic gate)

```python
coord_cap = 0.5 * (1 + clip(signal, -1, 1))
p_cooperate = coord_cap               # ∈ [0, 1]
cooperate = rng_decision.random() < p_cooperate
```

Decision RNG stream: seed+4000, isolated per agent×tick.

## 4. Physics measurements (pre-implementation)

### Precursor detectability by tau

| tau | Δc_spectral (1 tick after precursor) | Detectable ticks (Δ>0.05) |
|-----|--------------------------------------|---------------------------|
| 1.5 | +0.108 | 8 |
| 2.0 | +0.111 | 8 |
| 2.5 | +0.088 | 8 |

**Selected tau range for tau scan:** 1.5, 2.0, 2.5, 3.0
**Expected best operating point:** 2.0 (good detectability, mixed spectral regime)

### Probabilistic policy calibration (no gate, min_coord=4, task_window=3)

| signal | CCR (simulated) |
|--------|-----------------|
| 0.0 (baseline) | 0.21 ± 0.07 |
| +0.3 | 0.43 ± 0.07 |
| +0.5 | 0.67 ± 0.09 |

Pilot calibration will determine whether window=3 or window=4 gives baseline
CCR ≈ 50-70%.

### Sample size

Target d=0.5 (medium), alpha=0.0083 (Bonferroni 6 comparisons), power=0.80:
n_required ≈ 49. Use n=40 paired trials (pilot-validated).
